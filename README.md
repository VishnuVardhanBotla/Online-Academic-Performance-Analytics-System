📊 Online Academic Performance Analytics System

An Online Academic Performance Analytics System developed using Python, Flask, and MySQL to manage student academic records, analyze examination results, and identify students who need academic improvement.

📌 Project Overview

The Online Academic Performance Analytics System is a web-based application designed to simplify academic record management and performance analysis.

The system helps manage student information and marks, analyze academic results, and provide useful insights into student performance.

🎯 Objectives

Maintain student academic records.

Manage student marks and examination details.

Analyze student academic performance.

Identify students who need academic improvement.

Simplify academic data management.

⚙️ Installation and Setup

1. Clone the Repository

git clone YOUR_GITHUB_REPOSITORY_URL

2. Navigate to the Project Folder

cd Online-Academic-Performance-Analytics

3. Create a Virtual Environment

python -m venv venv

Activate it:

Windows:

venv\Scripts\activate

Linux / macOS:

source venv/bin/activate

4. Install Dependencies

pip install -r requirements.txt

5. Configure the MySQL Database

Start your MySQL server.

Create the required database.

Import the SQL file if your project includes one.

Configure your database credentials using environment variables.

Never upload actual database passwords or secret keys to GitHub.

6. Run the Application

python app.py

Open your browser and visit:

http://127.0.0.1:5000/
